# PixelPet · GPT 重绘版 v0.9.0

Windows 桌面伙伴，使用 Python 和 Win32 原生接口，不依赖 Qt。发行版是单文件 exe，使用者无需安装 Python。

![角色图标](assets/app-icon.png)

## 启动

发行版：先退出旧版，再双击 `PixelPet-v0.9.0.exe`。源码版：安装 Python 3.14 后，运行 `python pet.py`；本机也可使用 `启动桌宠.bat`。

[Releases 下载页](https://github.com/REDEMPTION029/PixelPet/releases) · [更新记录](CHANGELOG.md) · [v0.9.0 完整说明](docs/更新记录-v0.9.0.md) · [手动发布清单](docs/GitHub手动发布.md)

人物图标同时出现在 Windows 任务栏和右下角托盘，exe 文件也使用同一图标。

拖动人物移动；点击头/身体触发表情；双击播放开心动作；右键菜单支持散步、睡觉/唤醒、缩放、置顶与退出。Ctrl + 滚轮缩放，托盘图标单击显隐、右键打开菜单。

## 本轮改变

v0.9.0 完成候选计划的五项 P0：

- 陪伴设置按基础、动画、专注、显示分组；动画页显示实时有效周期，提供安静/日常/活泼草稿预设、本页默认和独立预览。保存前不改变桌宠，取消不写配置。
- 位置锁定与整个人物鼠标穿透独立设置。托盘菜单顶部提供恢复交互、15 秒临时交互、找回到主屏幕；托盘不可用时拒绝开启穿透。
- 统一自动散步、随机动作、闲置打盹和闲聊事件的检查时机；被专注、隐藏、菜单或拖动抑制的事件过期丢弃，恢复后重新等待，不补播。托盘可查看最近 30 条动作原因。
- 一键安全模式临时使用 50% 大小、恢复交互并暂停自动动作；不清除原偏好或专注进度，退出后恢复原偏好。
- 设置支持 Tab、回车和 Esc。减少动态时保持人物静止，手动拖动不播放跑步/惯性，专注数字及完成提醒继续。

用法和验证见 [v0.9 P0 交付记录](docs/v0.9-P0交付记录.md)。本轮未实现全屏勿扰、靠近反应或动作包等 P1/P2 功能。

## 历史改变

v0.8.1 修正陪伴设置和动画节奏窗口的字体，统一使用微软雅黑 UI 正文、加重标题与 ClearType，按 DPI 缩放。卡通气泡和头顶时钟保持原风格。下一轮功能建议见 [GitHub 调研与开发方案](docs/下一阶段开发优化方案-2026-11-01.md)。

v0.8.0 加入“右键 → 陪伴设置 → 动画节奏”。待机与贴边默认 10 秒一轮；随机小动作 45 秒、自动散步 10 秒、闲置打盹 180 秒。可分别调整或关闭，并用统一频率 0.25/0.5/1/1.5/2 倍一起调整，也可暂停自动动作。倍率越低间隔越长，不改变单次动作帧速、手动互动或专注计时。设置保存后立即生效，重启保留。详见 [动画节奏设置](docs/v0.8动画节奏.md)。

v0.7.0 完成专注进度恢复、GPT 重绘八帧侧身动作、32 MiB 精灵缓存预算，以及宠物/计时面板/设置窗口的 DPI 适配。隐藏时释放精灵缓存、降低刷新频率。计时即时保存关键状态，每 15 秒检查点，重启扣除离线时间；暂停保持暂停，检测到系统时钟回退时暂停等待继续。

多屏验证与各项交付见 [v0.7 开发记录](docs/v0.7开发记录.md)。本机两块显示器均为 125%，已检查双屏工作区和 120 组模拟布局；不同 DPI 实体跨屏及物理拔插仍待实机验证。

v0.6.0 修复显示器/DPI 变化后原地跑动、拖动途中缩放跳位及关闭自动散步遗漏起步阶段的问题。陪伴设置新增惯性、边缘探头、提示音开关，专注 15/25/45/60 分钟和休息 5/10/15 分钟。时长设置用于下一轮，5 分钟快速入口保留；旧配置自动补充默认值。

当前交付见 [v0.7 开发记录](docs/v0.7开发记录.md)，历史审查见 [P0/P1 开发清单](docs/P0P1审查-v0.6.md)。

v0.5.3 增加松手后的二维惯性滑动，按最近 120 毫秒的拖动速度缓慢减速，最高速度受限；再次抓取、打开菜单或改变大小会停止惯性。到达左右边缘衔接探头，关闭探头时停在边界。拖动跑步周期由 320 毫秒减慢到 680 毫秒。

v0.5.3 将拖动改为左右跑动，按鼠标移动方向自动转向；GPT 重绘侧身跑动和探头姿态，两侧探头均看向屏幕前的你。保留左右边缘收起探头，以及人物头顶的卡通倒计时面板。人物拖到屏幕可用区域左右边缘松手后会探头；点击探头恢复站姿，可继续拖动拉出。

只有开始专注后才显示时钟及面板，未开始或结束计时后隐藏。专注及其休息阶段点击或拖动会展开面板。闲置 6 秒后，背景和按钮在 1.2 秒内渐退；正在进行的专注/休息数字与小钟图标一直保留，计时继续。中文使用系统幼圆，数字使用 Comic Sans MS；计时结束提示音可在右键菜单开关。

旧四帧步态已换成八个 GPT 侧身关键姿态，保留 680ms 拖动周期。不是骨骼动画或高帧率步态，细节与流畅度仍可打磨。本轮说明见 [v0.5.3 修正记录](docs/v0.5.3修正记录.md)，旧版说明见 [v0.5 交互记录](docs/v0.5交互记录.md)。

v0.4 增加坐下/站起过渡、扶眼镜动作、动作优先级与保护、原生陪伴设置、25/5 分钟专注/休息流程。专注期间不自动散步、不自动闲聊、不自动打盹；支持暂停、继续与结束。通过右键菜单进入这些功能。

v0.4 的过渡与动作保护仍保留；历史问题与边界见 [P0 修复记录](docs/P0修复记录-v0.4.md)。[陪伴内容脚本](docs/P1陪伴内容脚本.md)记录了 P1 内容。

六组旧动画已全部替换为 GPT 根据 `reference_original.png` 重绘的 36 张帧：待机、走路、摸头、身体点击、坐姿睡觉、开心跳跃。每帧使用独立时长，睡眠进入后只循环闭眼段。

角色动作由 GPT 绘制。脚本仅切分六格图、对齐画布和保存 PNG，不使用区域像素移动、切块扭动或程序绘制来伪造动作。原图未修改。第一版重绘仍需结合播放检查服装小细节和帧间连贯性，不承诺单次生图完全消除漂移。

下载源码后在本地打开 [动画预览](docs/动画预览.html)，可同时播放六组动作、逐帧检查或切换深浅背景。原始生图在 `assets/sheets/`，完整提示词在 `docs/generation_prompts.json`。

## 项目结构

```text
pet.py                  入口、日志、DPI、单实例
src/                    原生窗口、动画、行为、设置与文案
assets/                 正式动画帧、时长配置及 GPT 原稿
scripts/import_sheets.py 切图与画布对齐，不生成动作
scripts/import_p04.py    新姿态、人工锚点与过渡元数据
scripts/test_native.py   单元与原生窗口测试
scripts/build_exe.py     单文件 exe 构建
scripts/build_icon.py    从原始角色制作多尺寸图标
docs/                   动画预览、制作记录、提示词
runtime/                源码版本地配置与日志，不发布
reference_original.png  唯一人物参考，未改动
```

旧 Qt 代码和像素移动补帧工具已清除。本地旧备份、用户配置、日志和构建缓存不会上传 GitHub。

## 开发与验证

```powershell
python pet.py
python scripts/test_native.py --window
python scripts/test_p0.py --window
python scripts/import_sheets.py
python scripts/import_p04.py
python scripts/import_p05.py
python scripts/import_p07.py
python scripts/make_preview.py
python -m pip install -r requirements-build.txt
python scripts/build_exe.py
```

构建结果是 `release/PixelPet-v0.9.0.exe`，包含正式动作、陪伴内容和图标。无需 Qt、Pillow 或额外图像处理库。重新导入时依次运行四个 import 脚本，最后运行 `import_p07.py` 恢复新版步态与交互动作。

发行版配置与日志在 `%LOCALAPPDATA%\PixelPet`，不会写入 exe 的临时解包目录；源码版使用 `runtime/`。初次默认 50% 大小、自动散步关闭；缩放范围为 50%–200%。本版针对 Windows 10/11 x64，当前 Windows 11 电脑实测通过，其他系统版本和混合 DPI 多屏热插拔待验证。当前发行文件尚未代码签名。
