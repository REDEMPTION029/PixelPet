# v0.3.0 构建与验证

构建环境：当前电脑的 Python 3.14.4 x64、PyInstaller 6.21.0、Windows 11。使用 `python scripts/build_exe.py` 生成单文件、无控制台 `release/PixelPet.exe`，无需给使用者安装 Python。

图标来自原始角色的头部裁切，包含 16/24/32/48/64/128/256 七个尺寸。exe 资源、窗口大/小图标和托盘使用同一套人物图标；窗口使用 WS_EX_APPWINDOW，进程设置独立 AppUserModelID。没有为任务栏“固定图标”修改用户系统设置；用户可以自行固定。

资源通过 PyInstaller 随包读取，配置与日志独立保存到 `%LOCALAPPDATA%\PixelPet`，不依赖临时解包目录持久化。源码版仍写项目内 `runtime/`。

验证结果：7 项单元测试、36 帧预乘 alpha 校验、144 次原生窗口渲染、透明命中、缩放、动作与睡眠循环、散步、托盘、显隐、窗口边界和退出循环通过；新增窗口大/小图标句柄与任务栏样式检查通过。

打包后的 exe 自检返回 0：`frozen=true`，六组各六帧完整加载，人物任务栏与托盘图标句柄有效，消息循环退出正常。自检从实际打包资源加载素材，不依赖源码目录中的 PNG。

受当前浏览器自动化支持限制，本轮没有通过浏览器自动发布 GitHub，也没有声称远程仓库或 Release 已创建。已整理干净源码目录、源码 ZIP、Windows 运行包、发布说明与 SHA256，供手动上传。

尚未覆盖：其他 Windows 版本、混合 DPI 多屏全矩阵、代码签名。当前动画仍是首版 GPT 重绘关键帧，细节一致性与动作衔接需要继续改进。
