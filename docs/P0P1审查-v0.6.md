# v0.6.0 P0/P1 审查与开发清单

后续完成情况见 [v0.7 开发记录](v0.7开发记录.md)。本文件保留 v0.6 时点的审查状态。

此处 P0 表示当前应优先修复的状态与交互错误，P1 表示影响日常使用的配置和体验改进。依据现有代码和本地回归检查，不代表已经覆盖所有硬件环境。

| 优先级 | 问题或改进 | 结果 |
|---|---|---|
| P0 | 显示器/DPI 变化只清除散步目标，走路动画可能一直循环 | 已修复：取消拖动、惯性和目标，运动状态回到待机，再夹紧窗口并保存位置 |
| P0 | 拖动中缩放，拖动起点仍保留旧尺寸位置，后续可能跳位 | 已修复：先结束拖动并释放捕获，再围绕脚底缩放 |
| P0 | 起步阶段关闭自动散步，原判断只覆盖 walk | 已修复：覆盖 walkEnter，并以会话优先级请求停步过渡 |
| P0 | 上一轮完成消息待播放时开始新专注，可能混入旧消息 | 已修复：开始新轮清除待通知事件 |
| P1 | 惯性、边缘探头和提示音散落在菜单或无设置入口 | 已完成：集中到原生陪伴设置，保存后重启保留 |
| P1 | 专注和休息时间固定 | 已完成：专注 15/25/45/60，休息 5/10/15 分钟；下一轮生效，保留快速 5 分钟入口 |
| P1 | 专注中退出后进度丢失 | 待开发：独立会话存档，恢复时区分暂停、到期和系统时间变化 |
| P1 | 四帧步态仍有节奏与细节变化 | 待开发：经过评审的 8 帧跑步，按实际步幅匹配移动，逐帧检查镜框、发型和衣服 |
| P1 | 高倍率下缓存按张数限制，内存上限较宽松 | 待开发：改为按像素字节预算逐出，隐藏时减少刷新 |
| P1 | 混合 DPI 多屏及热插拔覆盖不足 | 待硬件验证：不同缩放比例、主屏切换、休眠恢复与最大倍率 |
| P2 | 素材包与更多轻量陪伴内容 | 待规划：先稳定离线使用，再扩展角色包与情绪反馈 |

本轮验证：22 项单元测试，252 次原生渲染检查；新增回归覆盖旧配置默认迁移、参数范围校验、起步时关闭散步、显示变化恢复、拖动中缩放、关闭惯性、设置保存及自定义专注/休息实际时长。打包后额外执行无界面资源与渲染自检。未宣称已经完成混合 DPI 硬件矩阵或所有动画的视觉验收。

技术栈保持本机 Python 3.14 + Win32/GDI+，不使用 Qt。
