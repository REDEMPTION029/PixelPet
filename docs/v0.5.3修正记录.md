# v0.5.3 惯性拖动与动画减速

拖动跑步周期从 320ms 放慢至 680ms。松手后的速度根据最近 120ms 的实际窗口位置估算，二维速度限制为 900px/s，以指数摩擦衰减，不添加重力或弹跳。停留超过 100ms 再松手不触发惯性。轻微慢拖低于起滑阈值则直接停下。

惯性到达左右边缘衔接探头；关闭探头时停在屏幕边界。再次抓取、右键菜单、隐藏、缩放和显示器变化都会取消滑动，手动动作也可打断。停稳后保存最终位置，避免重启回到松手点。

验证：21 项单元测试，覆盖速度方向、摩擦衰减、停留松手、重新抓取和帧率无关的位移；原生集成验证正常停稳、滑动中禁止自动散步、到边探头和关闭探头后的边界停止。
