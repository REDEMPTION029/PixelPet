# v0.4 陪伴内容脚本

创作方向：她是安静陪伴、偶尔有小表情的桌面伙伴。文案少用命令和催促；用户可以关掉自动闲聊，专注期间默认不散步、不自动闲聊、不自动打盹。手动点击、拖动和菜单仍可用。

| 场景 | 动作与节奏 | 文案示例 | 打扰规则 |
|---|---|---|---|
| 开始专注 | 抬手 → 扶镜 → 轻点头 → 放手 | 先扶好眼镜，陪你专注一会儿。 | 开始时显示一次；之后保持安静 |
| 专注中 | 保持待机和短眨眼 | 无自动文案 | 不定时催促，不重新播放开场动作 |
| 暂停 | 不强制切动作 | 计时暂停了，慢慢来。 | 只响应用户的暂停操作 |
| 继续 | 保留当前动作和剩余时间 | 继续这一小段，我陪着你。 | 不重置计时、不重新开始动作 |
| 专注完成 | 等正在进行的互动结束，再开心回应 | 这一段完成了，起来走两步吧。 | 只提醒一次，转入五分钟休息 |
| 休息完成 | 轻提示，保持当前姿势 | 下一轮由你决定，我在这里。 | 不自动开始下一轮 |
| 主动结束 | 保持当前姿势 | 这一轮结束了，辛苦啦。 | 不惩罚、不追加催促 |
| 唤醒 | 坐姿 → 半蹲 → 站起 | 醒啦。刚才做了个小小的梦。 | 完成起身后恢复待机 |
| 日常闲聊 | 待机时偶尔一句 | 我在这里，慢慢来就好。 | 可关闭，可选 45/75/150 秒级频率 |
| 深夜 | 沿用安静待机 | 今天已经做了很多，慢慢收尾吧。 | 只替换文案，不执行强制休眠 |

运行内容包：`assets/companion.json`。同一事件可配置多句候选；计时阶段和动作触发由程序管理，不把提示词当作行为规则。

原生“陪伴设置”面板提供自动散步、自动闲聊、闲置打盹、置顶、大小与闲聊频率。专注 25 分钟 / 短时专注 5 分钟、暂停/继续和结束在右键菜单中操作。完成专注后自动进入 5 分钟休息，但下一轮由用户主动开始。

当前计时仅在本次运行中有效，退出程序不会恢复未完成的计时。没有声音、全局键盘监听、联网或模型调用；完整开机自启管理不在本轮实现范围内。
