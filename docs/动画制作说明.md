# GPT 重绘动画制作说明

> 本文记录 v0.2/v0.3 的六套基础素材。v0.4 的新姿态、状态过渡、验收结果和未关闭问题见 `P0修复记录-v0.4.md`；完整新提示词见 `generation_prompts_v0.4.json`。

日期：2026-10-31。生成方式：内置 `image_gen`，未使用 CLI/API 备用方案。

## 人物与动作

`reference_original.png` 是唯一身份来源。保持脸型和五官关系、大黑框眼镜、分缝刘海、长黑发、海军蓝外套及浅色领口/袖边/门襟、白衬衫、磨损牛仔裤和彩色小细节、白色运动鞋与原图的像素感插画风格。

六组均由 GPT 重新绘制六个关键姿态。先生成待机稿，其他组同时参考原图与这张待机稿，帮助统一整套画法。实际生成模型由内置工具管理，不把无法核实的精确型号写入记录。完整英文提示词见 `generation_prompts.json`。

| 动作 | 绘制内容 | 节奏 |
|---|---|---|
| idle | 呼吸、肩膀放松、半闭眼、闭眼、睁眼、回位 | 眨眼段短停，站姿长停 |
| walk | 交替步态、抬腿屈膝、对侧摆臂、头发随动 | 6 帧循环 |
| headClick | 惊讶、脸红、抬手碰头发、闭眼歪头、放手 | 表情峰值停顿后回待机 |
| bodyClick | 惊讶、叉腰、摊手疑惑、小小抗议、缓和 | 一次播放后回待机 |
| sleep | 坐姿、困倦、闭眼点头与呼吸 | 前两帧只进入一次，循环后四帧 |
| happy | 预备、屈膝、起跳、腾空、落地、站起 | 峰值短停，落地缓冲 |

## 打包处理边界

每张 GPT 原稿是 1536×1024 RGBA，3 列×2 行。`scripts/import_sheets.py` 只做 PNG 解码、切分、按可见内容包围盒对齐完整角色和写入统一 512×512 透明画布。保留原稿 RGB/alpha 像素；没有分割眼、头发、腿或衣服来伪造动作，也没有从一张站姿合成其他姿态。

水平对齐去除生图排版造成的偏移；脚底统一在画布 y496。开心峰值脚底位于 y440，以保留腾空留白。对齐不能解决角色内部比例变化；这种问题需要重新生图或针对性重绘。

导出文件与 SHA256 记录在 `asset_report.json`。原生程序使用逐帧时长和睡眠循环起点；运行时缩放/镜像属于显示功能，不承担动作制作。

## 检查与限制

六张原稿已逐组查看，保留了主要人物特征，并画出了旧脚本无法表现的屈膝、手势和坐姿。它们是首版重绘关键帧，不是已完成的高帧率动画：镜框粗细、衣服纹理、牛仔裤小图案仍可能有帧间变化，走路周期也需要继续视觉打磨。

本轮运行验证：7 项单元测试通过（含独立帧时长与睡眠循环起点）；36 张帧的原生解码和预乘 alpha 检查通过；4 档大小共 144 次透明窗口渲染、动作回退、散步、菜单控制、托盘、显隐、边界与透明命中检查通过。实际桌面检查了待机、摸头抬手歪头和坐姿闭眼睡眠，透明边缘正常显示。

后续改进应直接编辑或重新生成有问题的关键帧，继续引用原图并明确要修的部位；不要重新引入区域像素移动脚本。所有新生图原稿及提示词应保存在项目内。
